# P0 — ломает функцию или данные

База: `352e2d6`. Коммит: `fix(UI-xx): …`.

## UI-01. Ctrl+N / Ctrl+O / Ctrl+S не срабатывают (ambiguous shortcut)

**Где:** `ui/main_window.py` меню ~386–390, тулбар ~540–542.

**Что:** `_action()` создаёт два разных `QAction` с одинаковыми `QKeySequence.New/Open/Save`. Qt пишет `QAction::event: Ambiguous shortcut overload` и не вызывает ни один.

**Исправление:**
- Создавать каждое действие один раз (`_create_actions()`), хранить в `self._actions['new']` и добавлять **тот же объект** в меню и тулбар.
- Правило: одна команда — один `QAction`. Проверить Start/Stop (`_act_start`, `_tb_stop`, кнопка NavBar) и «Метку» (~489 и ~549).

**Приёмка:** Ctrl+N, Ctrl+O, Ctrl+S, Ctrl+Shift+S работают. В консоли нет `Ambiguous shortcut`.

## UI-02. «Экспорт → График в PNG» падает с AttributeError

**Где:** `ui/main_window.py` ~1816–1835.

**Что:** `import pyqtgraph as pg` не тянет `pyqtgraph.exporters`.

**Исправление:** `import pyqtgraph.exporters`; экспорт `self._plot_area.plot_item()` (см. UI-43); `exporter.parameters()['width'] = 1920`. Опционально SVGExporter.

**Приёмка:** PNG сохраняется в новой сессии сразу после запуска.

## UI-03. Операции над выделением в live применяются к старому блоку

**Где:** `_update_stats`, `_copy_selection_to_block`, `_delete_selection_from_block`, `_current_block` в `ui/main_window.py`; меню в `ui/plot_area.py`.

**Исправление:** `_current_block()` → None если не IDLE; в live Copy/Delete disabled; `PlotArea.get_range_data(t0,t1)` для live-статистики без visual scale/offset.

## UI-04. Open / Recent / Import .pgc во время записи

**Исправление:** `_confirm_discard()`; блокировать Open/Recent/Import при state != IDLE; `_load_session(path)` со сбросом UI; удалять битые recent.

## UI-05. «Y/дел» работает наоборот

Модель: `y_per_div` ↔ `scale = 1/y_per_div`. `NoInsert` + `QDoubleValidator` + один обработчик. Единый форматтер.

## UI-06. Шкала времени врёт; зум за блок меняет только подпись

После setXRange читать фактический viewRange(). Ограничить max_idx. Кнопки +/− disabled на пределе. Limits maxXRange=span, minXRange=TIME_DIV_SEQ[0]*N_DIV.

## UI-07. Нет pan мышью; RMB/MMB ломают 1-2-5

Middle/Right = pan по X (`translateBy`). Ctrl+LMB = rect zoom + snap 1-2-5. Отключить scale по RMB. Синхрон галки Авто Y с ViewBox. Колесо по курсору; Ctrl+колесо = Y; Shift+колесо = pan времени.

## UI-08. Y-зум невидим при Авто Y

Любое ручное Y-действие выключает autorange и галку. `_static_dirty = True` в `y_zoom_all`.
