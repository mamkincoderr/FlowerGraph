# FlowerGraph UI review catalog

Полный текст задач собран для CLI-сессии. Читать в таком порядке:

1. `docs/CLI_HANDOFF.md` — правила, порядок, скрин-протокол
2. `docs/UI_TASKS.json` — индекс UI-01…UI-46 (`status`, `needs_repro`, файлы)
3. `docs/ui-review/P0.md` — полные формулировки P0 (начать отсюда)

База: commit `352e2d6`, `APP_VERSION = 0.7.2.123`.
Коммит: `fix(UI-xx): …`.
Не менять `.fgd` и протоколы без нужды.

Сводка: P0=8 (UI-01…08), P1=14 (UI-09…22), P2=18 (UI-23…40), P3=6 (UI-41…46).

Если в рабочей копии есть расширенный `docs/UI_NAV_REVIEW.md` (≈535 строк) — он и есть полный каталог P0–P3 + чек-лист. PDF-оригинал — вложение сессии.
